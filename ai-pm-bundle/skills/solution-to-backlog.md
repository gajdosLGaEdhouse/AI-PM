# Skill Contract: Solution Design to Backlog / WBS

## Purpose
Transform solution design, scope, and user scenarios into a first-pass `artifacts/backlog.md` or WBS that is usable for planning and roadmap creation.

## When to use
Use once scope and solution direction are sufficiently understood to decompose work into implementable slices and supporting quality activities.

## Primary methodology coverage
- 03-02 Solution design
- 03-03 Scope and estimates

## Required inputs
- architecture summary or solution design,
- scope baseline,
- user scenarios or use cases.

## Output artifacts
- `artifacts/backlog.md`
- dependency map
- suggested follow-up questions

## Guardrails
- include enabling and QA work,
- distinguish feature work from uncertainty-reduction work,
- do not pretend estimate readiness if major unknowns remain.
