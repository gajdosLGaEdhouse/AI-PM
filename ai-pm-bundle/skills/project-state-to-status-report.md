# Skill Contract: Project State to Status Report

## Purpose
Generate `artifacts/status-reports/<date>-status-report.md` from the current project state for internal or customer reporting.

## When to use
Use on a regular cadence, before steering meetings, or before customer reporting checkpoints.

## Primary methodology coverage
- 04-04 Monitoring
- 04-05 Customer reporting

## Required inputs
- roadmap,
- completed or delivered items,
- current risks and issues,
- metrics if available.

## Guardrails
- do not overstate progress,
- do not hide slippage or material risk,
- state clearly when metrics or evidence are incomplete.
