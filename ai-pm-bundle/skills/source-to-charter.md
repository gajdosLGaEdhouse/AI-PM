# Skill Contract: Source Docs to Project Charter

## Purpose
Create `artifacts/project-charter.md` from commercial, discovery, and project source materials using the official project-charter template.

## When to use
Use during initiation or when the project lacks a current charter.

## Primary methodology coverage
- 02-01 Contract review
- 02-02 Project goal
- 02-03 Scope definition
- 02-05 Roles and responsibilities
- 02-06 Project governance

## Required inputs
- at least one commercial or project brief source,
- and at least one of: discovery notes, stakeholder list, milestone note, or existing charter draft.

## Output artifacts
- `artifacts/project-charter.md`
- suggested updates for `artifacts/methodology-execution-log.md`
- suggested updates for `artifacts/decision-log.md` if needed

## Required output sections
Use the official template structure.
Also include:
- `Assumptions`
- `Open questions`
- `Source basis`

## Validation checks
- project goal is explicit,
- expected outputs are visible,
- customer and supplier are identifiable,
- key roles are represented or marked TBD,
- governance or delivery mode is visible.

## Guardrails
- do not finalize if project goal and outputs remain vague,
- do not invent dates, owners, or approvals,
- keep assumptions explicit.
