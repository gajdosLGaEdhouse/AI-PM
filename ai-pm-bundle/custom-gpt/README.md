# Custom GPT Edition

This folder repackages the AI PM Bundle for use as a Custom GPT knowledge pack.

## What to use
1. Paste `GPT-BUILDER-INSTRUCTIONS.md` into the GPT Instructions field.
2. Upload the files listed in `KNOWLEDGE-PACK-MANIFEST.md` as GPT Knowledge.
3. Use `HANDOFF-CHECKLIST.md` to verify behavior.

## Goal
Use the bundle as a **Custom GPT for project setup and PM orchestration** while keeping the core methodology portable.
