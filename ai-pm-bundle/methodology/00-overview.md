# Methodology Overview

This bundle translates the Edhouse project-management methodology into structured source files that humans and AI can use together.

Each methodology activity file contains:
- a machine-readable frontmatter block,
- practical guidance for the activity,
- expected artifacts,
- suggested AI support,
- and a mandatory **Project execution (Provedeni)** section.

## How to use the methodology files
Use methodology files as the reusable source of truth for **how** a project should be run.
Use project sources and accepted artifacts as the source of truth for **what is true** on the project.

For every relevant activity:
1. review the guidance,
2. create or update the expected artifacts,
3. record what was actually done in the execution note,
4. link the resulting project files.

## Interpretation rules
- Recommendations are recommended practices, not mandatory rituals.
- Techniques are methods to apply when useful.
- Outputs are the preferred artifacts to create and maintain.
- If an activity is skipped, document why.
- AI may draft and check, but humans own the actual project state.
