# Template Alignment Notes

These templates are working Markdown and CSV representations aligned to the supplied project-management templates.

Design choice:
- working artifacts stay in Markdown or CSV for portability and agent-friendliness,
- section structure and controlled vocabulary follow the real templates,
- export to DOCX or XLSX can be added later with minimal remapping.

Aligned areas:
- project charter structure follows the Zakládací listina pattern,
- communication plan follows the supplied communication-plan sections,
- risk register follows the supplied categories and status vocabulary,
- RACI follows the role-column pattern used in the provided matrix.
