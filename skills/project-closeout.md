# Skill Contract: Project Closeout

## Purpose
Assemble the closeout package for a completed or paused project: handover checklist, closure summary, lessons learned, and methodology feedback.

## When to use
Use when a project is ending, pausing, or transferring into maintenance.

## Primary methodology coverage
- 05-01 Handover
- 05-02 Retrospective
- 05-03 Commercial close
- 06-01 Partial handover
- 06-02 Project evaluation
- 06-03 Commercial pause

## Required inputs
- final project artifacts,
- handover evidence if available,
- lessons learned notes if available.

## Output artifacts
- `artifacts/handover/closeout-summary.md`
- `artifacts/handover/handover-checklist.md`
- `artifacts/lessons-learned.md`

## Guardrails
- do not claim formal handover without evidence,
- do not lose unresolved obligations,
- keep pause vs closure explicit.
