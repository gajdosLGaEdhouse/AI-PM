# Example Project Instance: TWM

This example shows the recommended project-instance layout when the bundle is mounted as `pm-bundle/`.

```text
project-root/
  pm-bundle/
  project-config.yaml
  sources/
    README.md
    proposal.md
    discovery-notes.md
  artifacts/
    project-charter.md
    scope-baseline.md
    risk-register.csv
    methodology-execution-log.md
    decision-log.md
```

Use the real project sources as the source of truth. Do not treat this example as project content.
