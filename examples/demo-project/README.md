## Quick Start

### Learn the Bundle (15 min)
1. Read `DEMO-WALKTHROUGH.md`
2. Review `project-config.yaml`
3. Skim `sources/README.md`

### Study Real Artifacts (30 min)
1. Read `artifacts/project-charter.md`
2. Review `artifacts/scope-baseline.md`
3. Check `artifacts/decision-log.md`

### Create Your Own Project (2-3 hours)
1. Copy this folder as template
2. Replace config and source docs
3. Follow `documentation/STEP-BY-STEP-GUIDE.md`

### Use with LLM (1-2 hours)
1. Setup: `../../SETUP.md` or `../../HUMAN-SETUP.md`
2. Upload sources from `sources/`
3. Let LLM create artifacts incrementally

## The Project Scenario

A financial services firm needs automated compliance monitoring to reduce costs, improve accuracy, and stay regulatory-ready.

**Customer:** RegTech Finance Inc.  
**Problem:** Manual transaction review is expensive, error-prone, and hard to scale  
**Solution:** AI-assisted compliance dashboard with automated flagging and reporting  
**Value:** $360K annual cost savings + risk mitigation
