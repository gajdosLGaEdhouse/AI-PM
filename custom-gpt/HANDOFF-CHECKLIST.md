# Handoff Checklist

Use this checklist when turning the bundle into a Custom GPT.

## Paste into Instructions
- `GPT-BUILDER-INSTRUCTIONS.md`

## Upload as Knowledge
- all files listed in `KNOWLEDGE-PACK-MANIFEST.md`

## Recommended first test
Provide:
- one project brief or offer,
- one discovery note or technical note.

Then ask:

"Use the uploaded methodology bundle to initialize this project. First create a concise setup inventory, identify the likely phase, and then ask me for any missing information needed to draft a useful project charter."

## Success criteria
The GPT should:
- summarize available evidence,
- avoid pretending certainty,
- ask for missing high-value information,
- produce one useful first artifact instead of many generic documents.
